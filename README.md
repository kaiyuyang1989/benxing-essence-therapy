## 更新方式

改动页面内容后，运行 `build_content.py`、`build_editorial.py` 和 `check_public_copy.py`，再本机预览并检查桌面与手机宽度。课程日期、价格和海报必须与当期事实表同步。六本书以用户提供的 `WechatIMG5362.jpg` 海报所列版本为准；旧名《情商魔法训练营》不再另列。`梦的真相` 用 2021 年版，`儿童情商教育` 用 2022 年版；`内在父母与内在小孩的拥抱` 暂用海报局部呈现，封面对应印次待出版社核实并补高清图。每本提供独立介绍和外部书店购买链接，本站不提供图书下载。图书尚未在自家微信小店作为自营商品上架。制作说明只留在仓库文档，不进入对外页面。

以后增加一个公开节目，只需在 `dist/media.json` 的 `items` 数组中复制一条记录，修改 `kind`（`video` 或 `audio`）、语言、标题、简介、来源与 HTTPS 原节目网址；`watch.html` 会自动生成卡片，不需要改页面布局。上站前核对节目已公开、内容与署名准确，网站只做跳转。新的学员原话或课堂人物照片须先核清官网使用范围。
